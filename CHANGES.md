# Changes to the kit

2026-10-05: first version, written and tested on fictional data only.

2026-10-22: stress test on five export shapes (Stripe plus HubSpot, Chargebee, QuickBooks plus a wide Excel schedule, Maxio with resellers, 3,000 customer scale). Changes forced by it: Excel input (.xlsx); wide schedules (one column per month) melted automatically; exact duplicate schedule rows dropped with a note, duplicate invoice rows kept and flagged; fuzzy customer name match (ratio 0.88 or above, marked for review); a credit column inside the invoice row ("Credits Applied") treated as a credit line; more than one currency raises a note, no conversion; --profile stops after the profile; date and amount parsing vectorised (66,000 rows: 297 s to 57 s). Not handled on purpose: reseller parent and child roll up (recorded, not rolled up), currency conversion, invoices with no service period are placed in their invoice month and flagged.

2026-10-24: open sourced as arr-check (MIT). Added `receipt.py` (make, verify) and `receipt.json` written at the end of every run, imported rather than spawned so it also runs inside a browser runtime. pandas missing now gives one plain line instead of a traceback; openpyxl missing no longer stops the run (the workbook is skipped with a warning, every table is still in the csv files); an Excel input without openpyxl gives one plain line naming the file. No number changed; the fictional set's report.md is byte identical before and after. Forced by a five shape stress run (NetSuite, Xero, Zuora, Recurly, Salesforce CPQ with QuickBooks) in an interpreter without openpyxl.

2026-10-25: `bridge.csv` and `bridge_accounts.csv`, the monthly ARR bridge on three bases (schedule, invoices, supported) with a difference row, a "Bridge" sheet and a report section. Identity asserted every month. Started by Codex (CX-067), finished by Cowork. No existing number changed; the five key files are byte identical.

2026-10-25: deferred revenue implied by the invoices (`deferred_rollforward.csv`, `deferred_accounts.csv`, `journal.csv`, optional `--deferred-gl`), built by Claude Code. Cowork added: the periodless rule for QuickBooks Online (period inferred only from an exact whole multiple of the schedule MRR, marked on the line), the journal as a QuickBooks month end true up rather than a release of every month's revenue, and `example/quickbooks/` with a stated expected answer (49,300) that the kit reproduces. `unknown_lines` is written as a count (0, not 0.0). No figure in the five key files moved on the Larkspur set.
